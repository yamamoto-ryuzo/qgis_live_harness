GeoSuite — QGIS デスクトップ + WebGIS フルサイクル ツールスイート

GeoSuite は QGIS を中核に、データ取得から検索、Web 共有、出力（報告書生成）までを ワンストップで自動化するプラグイン群です。

このページは geo_suite リポジトリ （アーカイブ予定）の内容を移行・整理したものです。今後はこのページがスイート概要の正となります。

プロジェクト概要

  • 自動化対象: データの取り込み（ローカル / CKAN）→ 検索 → Web 共有 → レポート作成（PNG / PDF / XLSX）
  • 対象ユーザ: QGIS を業務で使い、社内共有や Web 公開を簡易化したい組織

ワークフロー概要

QGIS プロジェクト作成
    ↓
geo_userfunc（ユーザー定義コード整備：式関数・フック・マクロ）
    ↓
GeoImport（ローカル / CKAN から自動 GIS 化）
    ↓
GeoSearch（地図内検索）
    ↓
GeoWebView（スタイル込 Web 共有）
    ↓
報告書作成（GeoReport：PNG/PDF ／ geo_excel：Excel 帳票）

クイックスタート

  1. QGIS に各プラグインをインストール（プラグイン一覧の各トップページを参照）
  2. プロジェクト作成時に geo_userfunc で式関数・プロジェクトフック・マクロを整備
  3. GeoImport でデータを登録（CSV / CKAN）
  4. GeoSearch で対象範囲を検索・抽出
  5. GeoWebView でスタイル付きパッケージ／パーマリンクを生成し共有
  6. GeoReport でレイアウトを適用し、高解像度 PNG/PDF と出力メタデータを取得
  7. geo_excel で Excel 帳票を出力（Excel で配布・二次加工する報告書向け）

注: Excel (XLSX) 形式で画像を埋め込んだ「完全自動」報告書生成については各プラグイン README の 記載に差異があり、GeoReport の機能として確定的に記載されていない部分があります。 Excel 帳票は geo_excel が担当する形で整理しています（下記コンポーネント参照）。

コンポーネント

各コンポーネントはこのリポジトリの qgis-plugin/ で管理されています （上流リポジトリは各節を参照）。「実装済み（現状）」と「将来の拡張候補」を分離して記載します。 元の geo_suite では将来構想とされていた項目のうち、現在は実現済みのもの （PostGIS 対応、OGC サービス公開、Excel 帳票出力、AI/MCP 連携基盤）は現状に移してあります。 また「MCP 候補」のうち現行の bridge / REST / MCP / AI パネルの API 連携で 実現できるものは各コンポーネントの「現状」に統合し、 Vector DB 等の基盤を要するもののみを将来候補として残しています。

geo_userfunc — プロジェクト作成時のユーザー定義コード整備

トップページ: qgis-plugin/geo_userfunc/README.md

現状

  • <profile>/python/geo_userfunc/ の *.py を AST で型分類するライブラリ管理
  • @qgsfunction 式関数は式エンジンへ登録（ラベル・凡例・印刷式などプロジェクト内で即利用可）
  • openProject / saveProject / closeProject はプロジェクト信号へ配線（プロジェクト作成・開閉時の初期化処理に利用）
  • main(context) はマクロとしてメニュー／bridge から実行
  • 他プラグインのマクロを一元管理する共有レジストリ（実行メニューの集約）
  • AI から関数の発見・作成・登録・検証まで行える bridge と管理ダイアログを内蔵

GeoSuite の各段で使う式関数や初期化フックをプロジェクト作成時に整える前段のプラグインです。

GeoImport — 自動 GIS 化（CKAN / ローカル）

トップページ: qgis-plugin/geo_import/README.md · 上流リポジトリ: qgis-data-catalog-integration

現状

  • CKAN サーバおよびローカル CKAN 互換フォルダからの検索・取り込み対応
  • CSV の区切り文字自動判定、文字コード自動判定（UTF-8 / CP932 等）
  • 緯度/経度カラムがあれば自動でポイントジオメトリ化
  • SQLite ベースのローカルキャッシュによる検索高速化
  • bridge 経由の AI/MCP 操作: search → results → selectResult → loadSelected で検索からレイヤ追加まで API で完結
  • AI による取り込み支援: pyeval でファイルサンプルを読み取り、フィールドマッピング案・座標列推定・品質チェック・修正ルール・取り込み方針を提案

将来の拡張候補

  • STAC / DCAT によるメタデータ連携と自動インデックス化
  • 大容量データ取り込み（並列処理・ストリーミング、S3 互換ストレージ対応）
  • 点群（LAS/LAZ）・3D フィーチャ取り込み（PDAL 統合）
  • 自動ジオリファレンス・座標系検出の改善、データ品質チェック自動化

将来の拡張候補

  • メタ・サンプルの埋め込み登録（RAG 連携）: ファイルメタやサンプル記述を Vector DB に登録し、以降の検索／QA／自動説明生成で再利用（Vector DB 基盤が未導入）
  • STAC / CKAN 登録用メタデータの自動生成・連携

GeoSearch — 地図内検索（属性・空間検索）

トップページ: qgis-plugin/geo_search/README.md · 上流リポジトリ: GEO-search-plugin

現状

  • 地番・所有者・一般属性検索など複数検索タイプに対応
  • 結果はレイヤ別タブで表示、クリックで地図上にズーム/選択
  • selectTheme によるテーマ適用、加算表示モード（既存表示を保持しつつ重ね表示）
  • QGIS レイヤ・ファイル・PostGIS データベースを検索ソースとして利用可能
  • Qt5/Qt6（QGIS 3.x）互換対応のための安定化措置
  • bridge 経由の AI/MCP 操作: search / suggest / searchOptions / tabOptions / results / zoom で検索〜候補提示〜絞り込み〜地図ズームまで API で完結。会話文脈からの検索意図補完も可能

将来の拡張候補

  • Elasticsearch / OpenSearch 等を用いた全文検索強化（PostGIS は検索ソースとして対応済み）
  • 複数データソース横断のフェデレーション検索、空間インデックス最適化
  • 時系列データ・バージョン管理（履歴検索、差分抽出）
  • 空間解析を組み込んだフィルタ（バッファ、空間結合、属性スコアリング）
  • 機械学習を用いた検索補助（クラスタリング、異常検知）

将来の拡張候補

  • RAG（文脈＋ドキュメント検索）連携: 埋め込み検索で社内文書や仕様を参照し、source_refs と confidence を付けた根拠付き回答（Vector DB 基盤が未導入）
  • 過去クエリ・選択状態の埋め込みによる類似検索・意図補完の永続化

GeoWebView — スタイル込 Web 共有

トップページ: qgis-plugin/geo_webview/README.md · 上流リポジトリ: geo_webview

現状

  • QGIS の表示状態（中心・ズーム・レイヤ可視性・スタイル）をパーマリンク、HTML/PNG パッケージとして出力
  • .kasc+DATA/ のサーバレス配信（KASUGAI Canvas 4エンジン再生）＋内蔵 HTTP サーバー（/kasugai・/export-data/・/present・/screenshot）での社内配信
  • QGIS スタイル(.qml)をパッケージに同梱し、クライアント側コンパイルで復元
  • 高解像度 PNG 出力、Office（Excel/PowerPoint）向け出力テンプレの例示
  • bridge 経由の AI/MCP 操作: startServer / generatePermalink / kasugaiExport / navigate / endpoints で共有作業を API で完結。出力形式・公開範囲の推奨や説明文生成も可能

README 備考: ベクタタイルサーバ（VectorTile）導入は README にて「あきらめた開発」と明記されており、当面は開発保留です。

将来の拡張候補

  • QGIS 3D 表示のスナップショット / Cesium・Re:Earth へのエクスポート連携
  • 点群ビジュアライゼーション（Entwine / Potree / Cesium・Re:Earth 連携）
  • WebSocket 等を使ったリアルタイム更新（配信はサーバレス .kasc+DATA/ が主経路）
  • ベクタタイル生成・タイルキャッシュ・CDN 配信パターン

将来の拡張候補

  • 運用マニュアルや過去公開ノートの埋め込み検索（RAG）による根拠付き説明文生成
  • 組織のスタイルガイド・過去プロジェクトのスタイル事例を埋め込み化したスタイル転写案の品質向上

GeoReport — レイアウト編集・出力＋報告書生成

トップページ: qgis-plugin/geo_report/README.md · 上流リポジトリ: qgis-layoutitem-selector

現状

  • レイアウトテンプレートの保存・一括適用（JSON ベースのテンプレ化）
  • レイアウト内アイテム（地図・凡例・ラベル・画像等）のバッチ編集
  • 印刷範囲（RubberBand）表示とマウスでの移動・調整
  • Atlas 的な複数図面の一括出力、PNG/PDF の高解像度出力
  • 多言語対応や安定性向上のための改善がドキュメント化
  • Excel (XLSX) 帳票出力は姉妹プラグイン geo_excel として実現（下記）
  • bridge 経由の AI/MCP 操作: listLayouts / selectLayout / listItems / itemProperties / setItemProperties / saveLayoutProperties でレイアウト選択〜アイテム編集〜テンプレート保存まで API で完結。source_refs 付きキャプション生成も可能

将来の拡張候補

  • 3D スナップショット統合（静止画・簡易インタラクティブビュー）
  • 点群・断面図生成（断面抽出、属性統計、サマリ表）
  • Jupyter / Papermill による再現可能なレポート生成フロー
  • 大量出力のための分散実行と途中再開機能

将来の拡張候補

  • 過去報告との類似/差分検出（埋め込み検索）: 過去の報告書・図版を Vector DB に登録して類似図版や差分を抽出し、レビュー用メタを生成（Vector DB 基盤が未導入）

geo_excel — Excel 帳票出力

トップページ: qgis-plugin/geo_excel/README.md · 上流リポジトリ: QGIS-exportExcel

現状

  • QGIS-exportExcel のレイヤアクション用スクリプトをプラグインメニューから実行（アクティブレイヤ・選択地物が対象）
  • レイヤ変数（xlsout_*）による帳票・出力先の設定
  • geo_userfunc の共有レジストリ経由で実行メニューを他プラグインと集約可能
  • bridge 経由の AI/MCP 操作（帳票実行・レイヤ変数設定・環境チェック。modal ダイアログは自動応答で吸収）
  • 実行には win32com（pywin32）と Excel が必要

MCP / AI 連携 — 共通事項

現状（実現済み）: qgis_live_driver が MCP Streamable HTTP サーバー （/mcp）・REST・ファイル JSONL・AI アシスタントパネルを提供し、 上記各プラグインの bridge を bridge_call 経由で AI から操作できます。 残る将来候補は次の通りです。

  • 埋め込み / Vector DB 利用によるナレッジ連携: 社内ドキュメントや過去プロジェクトのメタを埋め込み化して、RAG として活用（MCP の context_id をキーに検索）

想定シナリオ

  • 社内報告書作成: GeoImport → GeoSearch → GeoWebView → GeoReport / geo_excel
  • Web 地図公開: GeoWebView でパッケージ化・パーマリンク共有
  • 大量出力: レイアウトテンプレートを用いた一括出力（例: 100 枚の Atlas）

関連ツール

qgis_launcher — QGIS / QField ランチャー

Rust 製の QGIS ランチャーで、GeoSuite プラグインと同じ geo_custom プロファイル経由で連携します。 Web UI / CLI / HTTP API からの起動、ユーザーロール制御、プロファイル配布、ローカル自動同期、 NSIS ベースの自動更新を備えます。

トップページ: launcher/qgis_launcher/README.md

yr-qgis-launcher — ポータブル QGIS・QField 環境ランチャー

リポジトリ: yr-qgis-launcher

現状（確認: 2025-11-30）

  • ProjectFile.exe による指定プロジェクトの直接起動、および権限別 UI / startup.py を用いたレイヤ初期化機能
  • local-launcher.bat / qgislocalsync.config によるローカル同期（robocopy ベース）と、同期後の自動起動ワークフロー
  • ポータブル版 QGIS / QField のバージョン比較による差分同期と管理、組込済みプラグインのサンプル一覧を含む
  • Windows バッチ主体の構成のため、展開パスは英数字のみ、改行コード等の運用注意が README に記載されている

用途: オフライン/ポータブル環境配布や、BOX 等クラウドストレージからの同期を利用した統一実行環境構築に有用
