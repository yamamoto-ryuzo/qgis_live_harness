プラグイン別ドキュメント

qgis-plugin/ 配下の全プラグインのドキュメント。各ページは プラグインの README・metadata.txt から生成しています。

このページ群は python scripts/build-plugin-docs.py で qgis-plugin/<id>/README_JP.md(無ければ README.md) から自動生成されます。元ファイル更新後に再実行してください。

  • geo_driverLocalhost-only remote control driver for QGIS (token-authenticated MCP/REST/file API for local AI tools) plus a built-in AI assistant panel for OpenAI-compatible APIs and a hot-reload watcher for plugin development
    v0.16.0 — Harness 中核ドライバ(制御ハブ)
  • geo_userfuncユーザー定義Pythonコード(式関数/フック/マクロ)のライブラリ管理プラグイン
    v1.0.7 — GeoSuite 前段 — ユーザー定義コード整備
  • geo_importさまざまなデータセットを検索・追加できるQGISプラグインです
    v2.10.11 — GeoSuite — データ取り込み(CKAN/ローカル)
  • geo_searchQGIS用の地図検索システム。地番・所有者名・属性検索に対応し、結果はレイヤごとにタブ表示・ページング・表示フィールド選択が可能。タブごとの設定編集UI、マップテーマ切替（selectTheme）、追加表示モード（既存表示に重ねて検索結果を表示）を搭載。QGIS 4.x/Qt6対応。
    v4.4.10 — GeoSuite — 地図内検索
  • geo_webviewServerless web distribution of QGIS projects — export .kasc+DATA/ packages playable on KASUGAI Canvas multi-engines (Cesium/MapLibre/OpenLayers/Leaflet/GSI Maps/Navara); permalinks and an embedded HTTP server
    v4.13.1 — GeoSuite — スタイル込 Web 共有(.kasc)
  • geo_reportレイアウト選択、アイテム事前編集、テンプレート作成により効率的な地図作成ワークフローを実現するQGISプラグイン
    v2.9.8 — GeoSuite — 報告書(PNG/PDF)
  • geo_excelベクターレイヤの属性情報をExcel帳票として出力するスクリプト群(QGIS-exportExcel)の簡易プラグインラッパー
    v1.9.5 — GeoSuite — 報告書(Excel 帳票)
  • geo_legendDisplay only the necessary legends in a clear, easy-to-understand manner with Qt6 compatibility
    v2.8.0 — 凡例ドック(将来 GeoReport へ統合予定)
  • geo_launcherkasugai_qgis ランチャー(Rust/Axum)を QGIS 内からインストール/アンインストール・起動する連携プラグイン
    v1.1.2 — kasugai_qgis ランチャー連携

スイートとしての位置づけ

geo_userfunc → geo_import → geo_search → geo_webview → geo_report / geo_excel は GeoSuite のワークフロー(取り込み → 検索 → Web 共有 → 帳票出力)を構成します。geo_driver は全プラグインを遠隔操作する 制御ハブ(QGIS Live Driver)で、各プラグインの bridge API はこれ経由で AI から呼び出せます。
