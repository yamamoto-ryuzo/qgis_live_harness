Plugin

geo_webview

Serverless web distribution of QGIS projects — export .kasc+DATA/ packages playable on KASUGAI Canvas multi-engines (Cesium/MapLibre/OpenLayers/Leaflet/GSI Maps/Navara); permalinks and an embedded HTTP server

プラグイン IDgeo_webview
バージョン4.13.1
最小 QGIS4.0
ライセンスGPL-3.0
役割GeoSuite — スタイル込 Web 共有(.kasc)
出自upstream: geo_webview
関連リポジトリgeo_webview
ソースqgis-plugin/geo_webview/ · CHANGELOG

開いている QGIS プロジェクトを .kasc+DATA/ パッケージに出力し、 KASUGAI Canvas のマルチエンジン（Cesium / MapLibre / OpenLayers / Leaflet / GSI Maps / Navara）で 再生する QGIS プラグイン。出力物は静的ホスティングだけで配信できます。

ドキュメント

  • geo_webview ドキュメント（GitHub Pages） — 連携構成図・主な機能・マルチエンジン・導入ガイド・技術資料 （正本はこのフォルダの docs/ 配下の HTML。パネルの ? ボタンからも開けます）
  • INTEGRATION_JP.md / INTEGRATION.md — 外部クライアント連携方針（Re:Earth・ArcGIS）
  • SPEC_JP.md / SPEC.md — .kasc 行仕様・API・bridge
  • CHANGELOG.md — 変更履歴

クイックスタート

  1. このフォルダを QGIS の python/plugins/ に配置し、プラグインを有効化
  2. パネル「Web配信」で【Export】→ .kasc+DATA/+<engine>.html+index.html を出力
  3. 【▶Canvas】/【▶WebView】で即表示、【ZIP】で kasugai_canvas_<ch>.zip をダウンロードして静的ホストや CMS へ配置
