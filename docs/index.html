QGIS Live Harness

QGISプロセスをAI/外部スクリプトから自律駆動するための開発・制御・検証の基盤(ハーネス)。

QGIS Live Driver(MCPからQGISを操作するドライバ)

このリポジトリは単体のプラグイン製品ではなく、QGISに「取り付けて操縦する外側の装具」そのもの。 (リポジトリ/ディレクトリ名: qgis_live_harness)

  • 使い方・セットアップまずここ。Driver単体利用 / Harnessでのプラグイン開発の手順

  • QGIS Live HarnessDriverの上に乗るクライアントAPI・セッション管理・検証基盤

  • Harnessのプラグイン化何がQGIS内に移せて、何が構造上外に残るのか

基本構成 — 2つの柱

このリポジトリで開発・管理しているプロダクトは QGIS プラグイン群(geo_* 全9本) と KASUGAI シリーズ の2系統です。両者の橋渡しは geo_webview + KASUGAI Canvas が 主経路として担い、すべてのプラグインは AI 操作面(bridge) を備えます。

柱構成
QGISプラグイン群 取り込み(geo_import)→検索(geo_search)→Web共有(geo_webview)→報告書(geo_report/geo_excel)の GeoSuite ワークフロー＋ geo_legend / geo_userfunc / geo_launcher / geo_driver の 全9本(プラグイン一覧)
KASUGAIシリーズ KASUGAI Canvas(.kasc を再生するマルチエンジン WebGIS)と kasugai_qgis(Rust製 QGIS/QField ランチャー)の関連プロダクト群

連携: geo_webview + KASUGAI Canvas

QGIS プロジェクトは geo_webview がレイヤツリー・スタイル(.qml)・表示状態を .kasc + canvas_data/ として出力し、KASUGAI Canvas がブラウザ(またはローカルアプリ)で そのまま再生します。/live 経路ではカメラ追従・選択表示・レイヤ編集差分の リアルタイム双方向同期が行え、QGIS=編集・生成 / Canvas=高速表示の2画面運用が主な使い方です。 Canvas 側からは内蔵 AI チャットが geo_driver の MCP 経路を通じて QGIS を操作できます。

AI機能 — 全プラグインが AI 操作面を持つ

  • geo_driver(制御ハブ): pyeval(QGIS内任意Python)/bridge_call/ describe_plugins/スクリーンショットをファイルJSONL・REST /api/*・MCP /mcp で公開。 内蔵 AI アシスタントパネル(OpenAI互換/Anthropic/Gemini/Azure OpenAI/GitHub Copilot)も搭載
  • 各プラグインの bridge.py: <id>Bridge が操作APIを公開し、 pluginInfo() 標準スキーマで自己記述。describe_plugins カタログから AI が ロード中プラグインの機能を自動発見して実行・検証できる
  • QGIS Live Harness(開発基盤): AI が「書く→devreload で実機反映→pyeval/スクショで観測 →test:live で検証」を人間なしで反復するエージェンティックループの基盤(下記)

環境要件

  • Windows 10/11 専用(deploy/起動スクリプトがPowerShell実装)
  • QGIS 4.0.x、Qt6/PyQt6。C:\Program Files\QGIS* から自動検出(別場所は QGIS_EXE env)
  • Node.js 24+ (Harness側クライアント用。Driver単体利用なら不要)
  • Python 3.13+ (ユニットテスト用。pip install pytest)

注意

  • pyeval/devreload は任意コード実行を含むため、Driver側は localhost限定・セッショントークン認証必須で保護される (トークンはユーザ限定ACLファイルにのみ保存)。有効化は WEBENGINE_LIVE_DIR env またはメニュートグル。 脅威モデルはセキュリティ、配布手順はプラグイン配布を参照
  • 重いQGIS操作(大きなプロジェクトでのレイヤーアクティブ化等)の直後は JS側evalが一時的に飢餓することがある。その場合はpyevalで確認する
  • 詳細な仕組み・制約は AGENTS.md を参照
