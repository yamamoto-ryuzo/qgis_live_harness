QGIS Live Harness

QGISプロセスをAI/外部スクリプトから自律駆動するための開発・制御・検証の基盤(ハーネス)。 このリポジトリは単体のプラグイン製品ではなく、QGISに「取り付けて操縦する外側の装具」そのもの。 (リポジトリ/ディレクトリ名: qgis_live_harness)

層 名前 役割
QGIS側の手 QGIS Live Driver (qgis_live_driver) QGIS内で動く制御専用プラグイン。このリポジトリに依存しない汎用部品で、任意のQGISへ単独導入して遠隔操作面を得られる
E2Eプラグイン開発・検証環境
(外側の装具)		 QGIS Live Harness (このリポジトリ全体) Driverの操作面の上に乗る、クライアントAPI・セッション管理・ホットリロード・検証の基盤。リポジトリがあって初めて成り立つ

さらに qgis-plugin/webengine_plugin/ を、Harness上で育てる開発対象プラグインの 「器」(Qt WebEngineベースのテンプレート)として同梱する。

  • Driverだけ使う: python/plugins/ へのコピーで成立。ファイルJSONL・REST・MCPの 操作面を持ち、リポジトリもNodeも不要
  • Harnessとして使う: このリポジトリを開けば、高水準クライアント・ ensure/reload/devreload・L1/L2テスト・MCPアダプタが揃う

この上で回るのは エージェンティックループ: AIが「書く→devreloadで実機反映→ eval/pyeval/スクショで観測→test:liveで検証」を人間なしで反復する。

環境要件

  • QGIS 4.0.1 (C:\Program Files\QGIS 4.0.1)、Qt6/PyQt6
  • Node.js 24+ (Harness側クライアント用。Driver単体利用なら不要)
  • Python 3.13+ (ユニットテスト用)
  • Windowsデスクトップセッション(常駐QGISモデルのため)

注意

  • pyeval/devreload は任意コード実行を含む 開発専用機能。 WEBENGINE_LIVE_DIR/WEBENGINE_DEV_SRC 設定時のみ有効。 配布手順は上記「プラグイン配布」節を参照
  • 重いQGIS操作(大きなプロジェクトでのレイヤーアクティブ化等)の直後は JS側evalが一時的に飢餓することがある。その場合はpyevalで確認する
  • 詳細な仕組み・制約は AGENTS.md を参照
