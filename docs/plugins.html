プラグイン一覧

このリポジトリで開発・管理している QGIS プラグインの概要とトップページへのリンク集です。

GeoSuite（GEO シリーズ）

geo_* 系プラグインのうち geo_userfunc / GeoImport / GeoSearch / GeoWebView / GeoReport / geo_excel は GeoSuite — QGIS デスクトップ + WebGIS フルサイクル ツールスイート — の構成要素です。 データの取り込み（ローカル / CKAN）→ 検索 → Web 共有 → 報告書作成（PDF / Excel）までを ワンストップで自動化することを目的としたプラグイン群で、次のワークフローを想定しています。

QGIS プロジェクト作成 → geo_userfunc（ユーザー定義コード整備） → GeoImport（ローカル / CKAN から自動 GIS 化） → GeoSearch（地図内検索） → GeoWebView（スタイル込 Web 共有） → 報告書作成（GeoReport：レイアウト編集・PNG/PDF 出力 ／ geo_excel：Excel 帳票出力）

報告書作成は出力形式で2系統に分かれます。GeoReport は QGIS レイアウトを テンプレート化して PNG/PDF を高解像度出力する系統、geo_excel は レイヤデータを Excel 帳票テンプレートへ流し込む系統です。 用途（印刷用図面・帳票か、Excel で配布・二次加工する報告書か）に応じて使い分けます。

想定シナリオ: 社内報告書作成（Import → Search → WebView → Report / geo_excel）、 Web 地図公開（WebView でパッケージ化・パーマリンク共有）、 大量出力（レイアウトテンプレートによる Atlas 的一括出力）。
スイート全体の詳細: GeoSuite（このサイト内） · 旧リポジトリ: geo_suite（アーカイブ予定）

geo_userfunc

GeoSuite 前段 — プロジェクト作成時のユーザー定義コード整備担当。 ユーザー定義 Python コードのライブラリ管理プラットフォーム。 <profile>/python/geo_userfunc/ の *.py を AST で型分類し、 @qgsfunction 式関数は式エンジンへ登録、openProject/saveProject/closeProject は プロジェクト信号へ配線、main(context) はマクロとして実行します。 他プラグインのマクロを一元管理する共有レジストリと、AI から関数の発見・作成・検証まで 行える bridge を備えます。

トップページ: qgis-plugin/geo_userfunc/README.md

geo_import

GeoSuite 構成要素 — 自動 GIS 化（CKAN / ローカル）担当。 さまざまなデータセットを検索・追加するデータ取り込みプラグイン。 追加したレイヤは共有のレイヤ整理サービス（layer_org）へ自動で渡すことができ、 プロファイルのルールに従ったグループ配置・リネーム・スタイル適用も行います。

トップページ: qgis-plugin/geo_import/README.md · 上流リポジトリ: qgis-data-catalog-integration

geo_search

GeoSuite 構成要素 — 地図内検索（属性・空間検索）担当。 地番・所有者名・属性によるマップ検索プラグイン。検索結果はレイヤごとのタブに表示され、 タブ単位で検索フィールド・表示フィールドを UI 上で設定できます。QGIS レイヤ・ファイル・ PostGIS データベースに対応し、大量データはページング表示。検索時にマップテーマを切り替える機能 （「検索前」への復元を含む）や、現在の表示に検索結果を重ねる追加表示モードも備えます。 日本語・英語 UI 対応、QGIS 4.x（Qt6）対応。

トップページ: qgis-plugin/geo_search/README.md · 上流リポジトリ: GEO-search-plugin

geo_webview

GeoSuite 構成要素 — スタイル込 Web 共有担当。 開いている QGIS プロジェクトを .kasc+DATA/ パッケージに出力し、 KASUGAI Canvas のマルチエンジン（Cesium/MapLibre/OpenLayers/Leaflet）で再生する サーバレス Web 配信プラグイン。内蔵 HTTP サーバーは /kasugai（出力・登録）・ /export-data/・/present・/screenshot・パーマリンク受領を提供します。 地図の表示状態（中心・ズーム・レイヤの表示・テーマ・スタイル）を URL で復元する パーマリンク機能も提供します。

トップページ: qgis-plugin/geo_webview/README.md · 連携方針: 外部サービス・クライアント連携（このサイト内） · 上流リポジトリ: geo_webview

報告書作成

GeoSuite の出力ステージを担う2系統のプラグインです。 印刷用図面・PDF 帳票は GeoReport、Excel で配布・二次加工する報告書は geo_excel が担当します。

geo_report — PNG/PDF 系

GeoSuite 構成要素 — 報告書作成（レイアウト編集・PNG/PDF 出力）担当。 レイアウト管理を強化する帳票プラグイン。プロジェクト内レイアウトの一覧・選択・ レイアウトマネージャの起動、レイアウトアイテムのプロパティ（位置・サイズ・内容）の事前編集、 レイアウト全体を JSON テンプレートとして保存して他レイアウトへ一括適用する機能を持ち、 統一デザインの複数図面・帳票を効率よく作成できます。日本語・英語対応。

トップページ: qgis-plugin/geo_report/README.md · 上流リポジトリ: qgis-layoutitem-selector

geo_excel — Excel 系

GeoSuite 構成要素 — 報告書作成（Excel 帳票出力）担当。 QGIS-exportExcel のレイヤアクション用スクリプトを簡易プラグイン化した Excel 帳票連携。 プラグインメニューからアクティブレイヤ・選択地物を対象に帳票を実行します。 レイヤ変数（xlsout_*）と win32com（pywin32）・Excel が必要で、 geo_userfunc の共有レジストリ経由で実行メニューを集約することもできます。

トップページ: qgis-plugin/geo_excel/README.md · 上流リポジトリ: QGIS-exportExcel

QGIS-legendView-main

選択レイヤの凡例をコンパクトに表示するドッキングウィジェット。 プロジェクト変数 legend_group_layer_name で表示する凡例を制御します。 日本語・英語対応、QGIS 4.x（Qt6）対応。

トップページ: qgis-plugin/QGIS-legendView-main/README.md

qgis_live_driver

QGIS 内部を外部クライアントへ公開する制御専用プラグインで、この Harness の中核。 ファイル JSONL・REST /api/*・MCP Streamable HTTP（/mcp）の3経路で 任意 Python/JS の実行・地図キャンバスのスクリーンショットを提供します （localhost 限定・セッショントークン認証）。AI アシスタントパネル・ホットリロード・ GeoSuite 共有ツールバー・レイヤ整理サービス（layer_org）も内蔵。

トップページ: driver.html（このサイト内） / ソース qgis-plugin/qgis_live_driver/README.md

連携ソフトウェア

qgis_launcher

Rust 製の QGIS ランチャー。QGIS プラグインではなく、同じ geo_custom プロファイル 経由で連携する独立ソフトウェアです。Web UI / CLI / HTTP API から QGIS・QField を起動し、 ユーザーロール制御・プロファイル配布・ローカル自動同期・NSIS ベースの自動更新を備えます。 dev_mode で QGIS Live Harness の環境変数を注入して開発モード起動も可能です。 GeoSuite の関連ツールとしては、ポータブル QGIS / QField 環境ランチャー yr-qgis-launcher もあります。

トップページ: launcher/qgis_launcher/README.md
