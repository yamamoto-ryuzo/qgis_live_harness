プラグイン一覧

このリポジトリで開発・管理している QGIS プラグインのトップページへのリンク集です。

プラグイン 概要 トップページ
geo_search 地番・所有者名・属性によるマップ検索。タブ式の結果表示・ページング・検索時のマップテーマ切替に対応 qgis-plugin/geo_search
geo_webview QGIS を軽量 OGC サーバー（WMS/WMTS/WFS）として起動し、地図表示状態を外部から復元するパーマリンク機能を提供 qgis-plugin/geo_webview
geo_report レイアウト管理・テンプレートの一括適用による帳票作成。複数図面の統一デザインを効率化 qgis-plugin/geo_report
geo_import さまざまなデータセットを検索・追加できるデータ取り込みプラグイン qgis-plugin/geo_import
geo_excel QGIS-exportExcel 系のレイヤアクションスクリプトをプラグインメニューから実行する Excel 帳票連携 qgis-plugin/geo_excel
geo_userfunc ユーザー定義 Python コード（式関数・プロジェクトフック・マクロ）のライブラリ管理と共有レジストリ qgis-plugin/geo_userfunc
QGIS-legendView-main 選択レイヤの凡例をコンパクトに表示するドッキングウィジェット（QGIS 4.x / Qt6 対応） qgis-plugin/QGIS-legendView-main
qgis_live_driver QGIS 内部を外部クライアントへ公開する制御ドライバ（REST / MCP / ファイル JSONL）。この Harness の中核 driver.html（このサイト内） / ソース

連携ソフトウェア

ソフトウェア 概要 トップページ
kasugai_qgis Rust 製の QGIS ランチャー。プラグインではなく、同じ geo_custom プロファイル経由で連携する独立ソフトウェア（インストーラー・自動更新つきで配布） qgis-plugin/kasugai_qgis
