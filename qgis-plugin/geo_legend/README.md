# geo_legend (upstream: QGIS-legendView)

**📖 日本語ドキュメント: <https://github.com/yamamoto-ryuzo/qgis_live_harness/tree/master/qgis-plugin/geo_legend/docs>**
（インストール・使い方・仕様の詳細はこちら。今後は GeoReport へ統合予定）

## Overview

A compact legend dock for QGIS that shows only the legend entries you
actually need, instead of the full layer panel legend. Originally
developed as open source commissioned by Soja City (upstream:
QGIS-legendView).

## Features

- Compact dock listing only the required legend items
- Target layer control via the `legend_group_layer_name` project variable
- English / Japanese UI (follows the system language)
- Requires QGIS 4.0+ (Qt6/PyQt6); Qt5 support was removed in 2.2.0
