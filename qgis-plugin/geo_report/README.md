# QGIS Layout Item Selector (`geo_report`)

**📖 日本語ドキュメント: <https://github.com/yamamoto-ryuzo/qgis_live_harness/tree/master/qgis-plugin/geo_report/docs>**
（インストール・使い方・仕様の詳細はこちら）

## Overview

A multifunctional report/layout plugin that lets you reuse a single
QGIS print layout as a template for many maps and ledgers — list and
select layouts, pre-edit layout item properties, and apply saved
templates in one shot.

## Features

- List/select project layouts and open the layout manager
- Pre-edit layout item properties (position, size, content)
- Save a whole layout as a JSON template and apply it to other layouts
- Consistent-design bulk drawing and PNG/PDF report output
- English / Japanese UI
